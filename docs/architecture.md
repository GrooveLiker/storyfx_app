# Архитектура прототипа

```
Микрофон (16 кГц, моно) ──┐
WAV-файл ─────────────────┼─► asr.py (Vosk, поток) ──► события текста
Ввод текста (--text) ─────┘        partial / final
                                         │
                        engine.py ◄──────┘
                        │        │
           actions.py ◄─┘        └─► scenes.py
   якорь темы + смысл части фразы    окно последних ~40 слов
   rubert-tiny2 + классификатор       rubert-tiny2 + ключевые слова сцены
          │                          гистерезис
          ▼                                 ▼
     play_sfx(id)                 set_ambience(сцена, погода)
          └──────────► audio.py ◄───────────┘
                    pygame.mixer: слои фона с кроссфейдом,
                    короткие звуки на свободных каналах
```

## Модули (`prototype/src/storyfx/`)

| Файл | Ответственность |
|---|---|
| `config.py` | пути, константы (частота, окна, пороги) |
| `textnorm.py` | токенизация, стемминг, ё→е |
| `actions.py` | `ActionMatcher`: часть фразы с якорем темы → звук по смыслу (или тишина) |
| `scenes.py` | `SceneTracker`: текст → (сцена, погода) с гистерезисом; эмбеддер подменяемый |
| `audio.py` | `AudioEngine` (pygame) и `NullAudio` (для тестов, только лог) |
| `asr.py` | источники текста: микрофон, WAV, stdin |
| `engine.py` | `StoryEngine`: склеивает всё, режимы `dnd` / `kids` |
| `cli.py`, `__main__.py` | командная строка |

## Ключевые механизмы

**Действия по смыслу (actions.py).** Фраза режется на части по союзам («и», «а», «но», «потом»…; союз перед «не» не режет: «так и не зарычал»). Часть со словом-якорем темы (лошадь, меч, дверь…) — кандидат на событие. Контекст = 2 слова до якоря … 4 слова после (может перейти через союз: «подошла к лошадке и погладила её», но не в следующую часть с якорем той же темы). Классификатор темы — логистическая регрессия на векторах rubert-tiny2, обучается на `examples` из `actions.yaml` при запуске (~1 с) — выбирает вариант или `_none` (тема есть, звука нет). Порог уверенности `ACTION_MIN_CONF`.

**Частичные результаты Vosk.** Vosk выдаёт гипотезу много раз за фразу и может переписать последние слова («ударил меня» → «ударил мечом»). Поэтому решение принимается, когда после якоря набралось 4 слова, началось следующее событие темы или фраза закончилась. Одна часть фразы решается один раз (ключ: фраза, начало части, тема). Плюс кулдаун на каждый звук. Задержка ~0,5–1,5 с — владелец подтвердил, что это приемлемо.

**Почему окно до якоря узкое (2 слова).** Vosk часто склеивает предложения без паузы («завыли волки воин выхватил меч»); широкое окно тянет в классификатор чужой смысл.

**Отрицания.** Если перед любым якорем (2 слова) есть «не», «нет», «ни», «без», или после него «нет» / «не было» — звука нет. «Орк упал и не встал» — звук есть: отрицание у другого слова.

**Сцена.** Каждые `SCENE_INTERVAL_S` секунд (и на каждой финальной фразе) окно текста сравнивается с описаниями сцен. Итог = косинусная близость + бонус за ключевые слова сцены. Смена сцены — если победитель выше порога и выиграл `SCENE_CONFIRM` раз подряд. Погода — отдельный слой, работает так же.

**Режимы.** `kids` — исключает звуки с флагом `scary`, громкость действий ниже. `dnd` — всё.

**Эхо.** Прототип не подавляет эхо; используйте наушники. На телефоне — системное подавление эха (Android AcousticEchoCanceler, iOS VoiceProcessingIO).
