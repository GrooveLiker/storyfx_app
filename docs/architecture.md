# Архитектура прототипа

```
Микрофон (16 кГц, моно) ──┐
WAV-файл ─────────────────┼─► asr.py (Vosk, поток) ──► события текста
Ввод текста (--text) ─────┘        partial / final
                                         │
                        engine.py ◄──────┘
                        │        │
          triggers.py ◄─┘        └─► scenes.py
   ключевые слова по основам         окно последних ~40 слов
   отрицания, кулдаун                rubert-tiny2 + ключевые слова сцены
          │                          гистерезис
          ▼                                 ▼
     play_sfx(id)                 set_ambience(сцена, погода)
          └──────────► audio.py ◄───────────┘
                    pygame.mixer: слои фона с кроссфейдом,
                    короткие звуки на свободных каналах
```

## Модули (`prototype/src/storyfx/`)

| Файл | Ответственность |
|---|---|
| `config.py` | пути, константы (частота, окна, пороги) |
| `textnorm.py` | токенизация, стемминг, ё→е |
| `triggers.py` | `TriggerMatcher`: текст → список id звуков действий |
| `scenes.py` | `SceneTracker`: текст → (сцена, погода) с гистерезисом; эмбеддер подменяемый |
| `audio.py` | `AudioEngine` (pygame) и `NullAudio` (для тестов, только лог) |
| `asr.py` | источники текста: микрофон, WAV, stdin |
| `engine.py` | `StoryEngine`: склеивает всё, режимы `dnd` / `kids` |
| `cli.py`, `__main__.py` | командная строка |

## Ключевые механизмы

**Частичные результаты Vosk.** Vosk выдаёт «частичную» гипотезу много раз за фразу. Триггеры проверяются по частичным результатам (ради скорости). Чтобы один и тот же удар не сработал многократно, запоминаем, на какой позиции слова в текущей фразе сработал триггер; после финального результата счётчик сбрасывается. Плюс кулдаун на каждый звук.

**Отрицания.** Если в 2 словах перед совпадением есть «не», «нет», «ни», «без» — триггер не срабатывает.

**Сцена.** Каждые `SCENE_INTERVAL_S` секунд (и на каждой финальной фразе) окно текста сравнивается с описаниями сцен. Итог = косинусная близость + бонус за ключевые слова сцены. Смена сцены — если победитель выше порога и выиграл `SCENE_CONFIRM` раз подряд. Погода — отдельный слой, работает так же.

**Режимы.** `kids` — исключает звуки с флагом `scary`, громкость действий ниже. `dnd` — всё.

**Эхо.** Прототип не подавляет эхо; используйте наушники. На телефоне — системное подавление эха (Android AcousticEchoCanceler, iOS VoiceProcessingIO).
