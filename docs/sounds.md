# Звуки, триггеры и сцены

## Файлы звуков

- `prototype/sounds/ambience/<id>.wav` — зацикленный фон (сцены и погода).
- `prototype/sounds/sfx/<id>.wav` — короткие звуки действий.
- Формат: WAV, 16 бит, 44,1 кГц, моно или стерео.
- Заглушки создаёт `tools/gen_sounds.py`. Чтобы заменить заглушку настоящим звуком, положите файл с тем же именем. Генератор существующие файлы не перезаписывает (кроме `--force`).
- Лицензию каждого внешнего файла записывайте в `prototype/sounds/LICENSES.md`.

## Триггеры действий — `prototype/data/triggers.yaml`

```yaml
sword_clash:                 # id = имя файла в sounds/sfx
  phrases: ["удар меч", "скрестили клинки", "звон стали"]
  cooldown: 1.5              # сек, необязательно
  scary: false               # true — не звучит в режиме kids
```

- Фраза — слова через пробел. Каждое слово приводится к основе (стемминг), поэтому «ударил мечом» совпадёт с «удар меч».
- Слова фразы должны идти по порядку; между ними допускается до 2 лишних слов («ударил *тяжёлым* мечом»).
- Слово, оканчивающееся на `*`, означает «начинается с»: `гром*` → гром, громыхнуло, громовой.

## Сцены — `prototype/data/scenes.yaml`

```yaml
scenes:
  forest:
    ambience: forest          # файл в sounds/ambience
    descriptions: ["густой лес, высокие деревья, пение птиц"]
    keywords: ["лес", "чащ*", "опушк*"]
weather:
  rain: {...}                 # то же, слой поверх сцены
```

Описания — 2–4 разные фразы о том, как звучит/выглядит место. Ключевые слова дают бонус к оценке сцены.

## Как проверить изменение

```powershell
./.venv/Scripts/python -m pytest -m "not slow"
./.venv/Scripts/python -m storyfx --text --no-audio   # вводите фразы, смотрите события
```
