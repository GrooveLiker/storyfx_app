# Звуки, действия и сцены

## Файлы звуков

- `prototype/sounds/ambience/<id>.wav` — зацикленный фон (сцены и погода).
- `prototype/sounds/sfx/<id>.wav` — короткие звуки действий.
- Формат: WAV, 16 бит, 44,1 кГц, моно или стерео.
- Заглушки создаёт `tools/gen_sounds.py`. Чтобы заменить заглушку настоящим звуком, положите файл с тем же именем. Генератор существующие файлы не перезаписывает (кроме `--force`).
- WAV-файлы не хранятся в git. Что выбрано — в `sounds/chosen.yaml` (в git), авторы — в `sounds/LICENSES.md` (генерируется).

## Настоящие звуки с Freesound (только CC0)

1. Ключ: https://freesound.org/apiv2/apply/ → форма «Create new API credential» → столбец **«Client secret/Api key»**. Сохранить одной строкой в `prototype/.freesound_key` (файл в .gitignore, никому не пересылать).
2. Кандидаты (по 5 на звук, ~10 минут на все 39): `python tools/fetch_freesound.py` (или `--only owl,bell`). Запросы — `data/freesound_queries.yaml`, по-английски.
3. Выбор на слух: `python tools/pick_sounds.py` (или `--auto` — взять №1 везде; `--only owl` — переизбрать).
4. На другом компьютере: `init.ps1` сам скачает выбранное (`fetch_freesound.py --chosen`), если есть ключ.

Обработка (`src/storyfx/soundproc.py`): моно 44,1 кГц; действия — без тишины по краям, не длиннее `cut`, ровная громкость; фон — `cut` секунд из середины записи, бесшовная петля с кроссфейдом 2 с. Скачиваются превью высокого качества (mp3 128 кбит/с) — для прототипа хватает; оригиналы требуют OAuth.

## Действия по смыслу — `prototype/data/actions.yaml`

```yaml
horse:                                   # тема
  topic: ["лошад*", "кон", "прискакал*"] # слова-якоря: без них тема не рассматривается
  cooldown: 4                            # сек до повтора того же звука, необязательно
  variants:
    horse_gallop:                        # id = имя файла sounds/sfx/horse_gallop.wav
      examples: ["лошадь прискакала", "всадник мчался галопом", ...]
    horse_snort:
      examples: ["он погладил лошадь", "конь фыркнул", ...]
    _none:                               # тема упомянута, звук не нужен
      examples: ["у рыцаря была лошадь", "он купил коня", ...]
```

**Как выбирается звук.** Если в части фразы есть якорь, классификатор темы сравнивает её по смыслу с `examples` и выбирает вариант. Ключевые слова тут только «включают» тему — решает смысл.

**Как писать примеры:**
- 6–10 на вариант, **разные** по словам и строению: другие глаголы, подлежащие, порядок слов.
- Обязательно `_none` с фразами, где тема упомянута «мимоходом» («у него была лошадь», «удар судьбы»). Без них будут ложные срабатывания.
- Если звук сработал не там — добавьте эту фразу (или похожую) в `_none`. Если не сработал — в нужный вариант. Консоль печатает и решения «тише» с причиной и уверенностью — по ним видно, что подправить.
- Не копируйте фразы из `tests/test_e2e.py::MEANING_CASES` — это контрольные фразы для проверки обобщения.

**Якоря (`topic`):** основа слова (`кон` → конь, коня, коню) или префикс со `*` (`лошад*`). Осторожно с короткими префиксами: `сов*` совпадёт с «совсем», `огр*` — с «огромный».

## Сцены — `prototype/data/scenes.yaml`

```yaml
scenes:
  forest:
    ambience: forest          # файл в sounds/ambience
    descriptions: ["густой лес, высокие деревья, пение птиц"]
    keywords: ["лес", "чащ*", "опушк*"]
overlays:
  rain: {ambience: rain, keywords: [...], stop: ["дожд* законч*"]}   # слой поверх сцены
```

Описания — 2–4 разные фразы о том, как звучит/выглядит место. Ключевые слова сцены переключают её сразу; без них сцена меняется по смыслу (нужно выиграть 2 оценки подряд).

Совет по описаниям: оценка сцены — близость к *среднему* всех описаний. Описание «про постройки» («огород, хлев, сарай») тянет среднее от того, что слышно. Пишите о звуках и происходящем. Не копируйте фразы из `tests/test_e2e.py::FAIRYTALE_SCENE_CASES` и `MOOD_CASES`.

**Каталог в браузере** — удобнее, чем `pick_sounds.py`: `run_catalog.cmd` (или `python tools/catalog.py`) → http://127.0.0.1:8765. Все звуки по разделам (голоса, действия, фоны), кто использует звук, текущий выбор и 5 вариантов; ▶ — послушать, «Выбрать» — поставить вариант, «Оставить ✓» — отметить проверенным (`sounds/reviewed.yaml`). Фильтры: не проверены / проверены / заглушки, поиск. Сервер слушает только 127.0.0.1. Запущенное приложение подхватит новый звук после перезапуска.

Выбрать без прослушивания (например, по названиям): `python tools/pick_sounds.py --pick owl=2,ambience/night=5`. Обработка поднимает громкость «щёлкающих» звуков (треск, капли) мягким ограничителем — `soundproc._level`.

## Персонажи — `prototype/data/characters.yaml`

```yaml
characters:
  bear: {sound: bear_growl, names: ["медвед*", "мишк*", "михайл* потапыч*"]}
  crow: {sound: crow_caw, names: ["=ворона", "=вороны"]}      # «=слово» — точное слово («вороной» конь — не ворона)
  dragon: {sound: roar, names: ["змей горыныч*", "дракон*"]}
```

Звук — файл `sounds/sfx/<sound>.wav`, можно переиспользовать звук действия. Новому звуку нужны: заглушка `sfx_<sound>` в `tools/gen_sounds.py` и запросы в `freesound_queries.yaml` (это проверяют тесты). Проверяйте имена на ложные совпадения: `кур` = «курил», `гус*` = «густой», `сов*` = «совсем», `баб* яг*` = «бабушка… ягоды» — примеры в `tests/test_characters.py`. Список персонажей и почему такие звуки — docs/characters.md.

## Фоновая музыка — `prototype/data/moods.yaml`

Четыре настроения: `calm` (спокойная), `cheerful` (весёлая), `tense` (тревожная), `action` (динамичная). Формат как у сцен (`music` вместо `ambience`, плюс `default` — с чего начинать). Настроение угадывается тем же механизмом, что и сцена; смена — плавная, 4 с (`MUSIC_CROSSFADE_MS`).

Музыка синтезируется кодом: `python tools/gen_music.py [--force]` → `sounds/music/*.wav` (свои звуки, лицензия не нужна; в git не хранятся, `init.ps1` создаёт их). Чтобы изменить мелодию или темп — правьте функцию `music_<id>` там же. Громкость — 4-е число в `config.VOLUMES`.

Включить/выключить: `--no-music` при запуске; в режиме `--text` — строка `!музыка`. В коде — `StoryEngine.set_music_enabled(bool)`: при включении сразу играет текущее настроение (оно отслеживается и при выключенной музыке).

## Как проверить изменение

```powershell
./.venv/Scripts/python -m pytest -m "not slow"
./.venv/Scripts/python -m pytest tests/test_e2e.py::test_actions_by_meaning -s   # точность по смыслу
./.venv/Scripts/python -m storyfx --text --no-audio                             # вводите фразы, смотрите решения
```
