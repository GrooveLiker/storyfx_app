# Персонажи 100 сказок → звук появления

Сказки и их номера — [fairytales.md](fairytales.md). Персонажи собраны разработчиком (Claude) по тем же 100 сказкам, как и места.

Звук появления звучит при первом упоминании персонажа и снова, если о нём не говорили 1,5 минуты (`CHARACTER_REINTRO_S`). Данные — `prototype/data/characters.yaml`.

Три слоя озвучки:
1. **окружение** — фон сцены и наложения (`scenes.yaml`);
2. **персонаж при появлении** — этот документ (`characters.yaml`);
3. **действие** — звук по смыслу фразы (`actions.yaml`).

Если какому-то из них нужен звук — добавить строку в `characters.yaml` (см. docs/sounds.md).

## Пересечения имён

- Длинное имя важнее короткого: «Дед Мороз» — это Мороз (лёд), а не дед; «Баба-яга» — ведьма, а не бабушка; «Соловей-разбойник» — свист, а не злой смех; «жар-птица» — волшебство, а не птица.
- «Змей» не используется отдельно: «змея» по-русски — та же основа. Дракон — `Змей Горыныч`, `дракон`; змея — `удав`, `кобра`.
- «Кур» не используется: совпадает с «курил». Курица — `курица`, `курочка`, `цыплята`.
